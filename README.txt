국소배기장치 설계 계산기 v1.7

GitHub Pages 게시:
1. github.com/new 에서 Public 저장소 hood-calculator 생성
2. 이 ZIP을 압축 해제하고 index.html, manifest.webmanifest, sw.js, icon.svg 네 파일을 저장소 최상위에 업로드 (README.txt는 선택)
3. Settings > Pages > Deploy from a branch > main > /(root) > Save
4. https://사용자명.github.io/hood-calculator/ 접속
5. 갤럭시 Chrome 메뉴에서 앱 설치 또는 홈 화면에 추가

참고: 표의 상용 덕트 mm는 실제 내경으로 확정된 값이 아닙니다. 내경 확인 후 입력값 수정 필요.
다중 슬롯형 A 정의와 각 경험식 적용 조건은 원본 설계 자료로 검증 필요.
